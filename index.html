Overview

RawDog is a no-code GUI for turning raw .txt and .csv data into clean plots. It's a fast, intuitive alternative to MATLAB and Python for signal analysis. Note: RawDog has no connection to adult content.

Quick Demo (30s)

Key Features

  • Instant workflow: Load → Parse → Process → Visualize
  • Signal operations: filter, normalize, resample, and more
  • Comparison tools: Bland-Altman, correlation, and error histograms
  • Customizable plots: Multi-subplot layouts with stylization options
  • Transparent backend: Inspect, edit, and run custom Python scripts

Install Instructions

Follow these steps to get started — no coding required.

  1. Download the correct .zip file for your system (see buttons above).
  2. Unzip and open the app:
    • Windows:
      1. Right-click the downloaded .zip file and select "Extract All..." to extract it
      2. Open the folder named GUI8
      3. Double-click GUI8.exe (Type = Application) to launch the tool
      4. Windows may show a warning "Windows prevented an unrecognized app from starting." If this happens:
        1. Click "More Info" in the warning window
        2. Click "Run anyway" to launch the tool
      (Note: The app is named "GUI8.exe" instead of "RawDog.exe" to avoid false virus detection.)
    • macOS:
      1. Double-click the downloaded .zip file to extract it
      2. Double-click RawDog.app to launch the tool
      3. You may see a security warning "cannot be opened because the developer cannot be verified." If this happens:
        1. Right-click (or Control-click) on the app
        2. Select "Open" from the context menu
        3. You'll see the warning again, but now with an "Open" button
        4. Click "Open" to launch the tool
  3. The app may take 1–2 minutes to launch the first time. This is expected — please be patient.
  4. Start with the included test data. Large datasets may take longer to load or may appear unresponsive at first — give it a moment.

Compatibility Notes:

  • macOS: Tested on macOS 12 and above. Compatible with both Intel and Apple Silicon (M1/M2) machines.
  • Windows: Tested on Windows 10 (64-bit). Compatibility with other versions (e.g. Windows 11 or older) has not been verified.
